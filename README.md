# Agent New Media Studio

用数据经营、用 AI 放大、由你拍板的经营工作台，运行在 DSH Desktop 之上。

一句话：**接数据 → 看数据 → AI 建议 → CEO 汇报 → 老板拍板 → CEO 派活 → Agent 执行 → CEO 验收 → 回数据。**
整个闭环里，老板只做一件事：拍板。

## 三个硬前提（都落在工程上，不是口号）

| 前提 | 落地方式 |
| --- | --- |
| 必须有客观数据 | CSV 导入生成不可变快照（`sha256` 去重），指标全部带 `snapshot_id`；数据源按 24h 节奏判绿/黄/红，超过阻断线直接红灯，看板不假装有数据 |
| AI 建议必须受管 | 建议只能以决策形式进入 `decisions` 收件箱，带证据、选项、风险等级和验证计划；没有 `approved` 的决策**在数据库层**就插不进任务（有触发器） |
| 关键动作必须老板拍板 | 审批只从界面发起；模型工具表里没有 `approve`，也没有执行外部动作的工具。R1 可回滚、R2 需审批、R3（上架/发布/投资买卖）需要额外确认 |

## 现在能做什么（v0.2.0 · Phase 0）

**形态**：整页看板，顶栏 7 个一级 Tab（总览 / 电商 / 内容 / 开源 / 投资 / AI 工作 / 待办），另加数据源与设置。
总览是一棵树：创始人 → CEO → 6 路 Agent，彩色连线上有流动光点；每张 Agent 卡下面挂这个岗位的三件事。

- **总览**：创始人卡「等你 N 件」、拍板/汇报两条管道、CEO 卡（几个源新鲜、巡查几条）、6 路 Agent 卡
  （主指标 + 上次/下次同步 + 状态灯），下面是 4 个数字、CEO 简报位、数据健康、最近活动。
- **状态灯**：绿 = 数据新鲜；黄 = 数据旧了；红 = 超过阻断线；灰 = 还没接数据。
  **黄灯和红灯的源不会被拿来做判断**，Agent 只会说缺什么，不会拿旧数字编结论。
- **单个 Agent 页**（电商/内容/开源/投资/知识库/助理）：主指标、近 14 天每天新增柱图
  （快照相减，空柱 = 没有数据，今天的柱子淡红）、数据源明细、可执行动作（带 R1/R2/R3 风险）、问这个 Agent。
- **待办**：决策收件箱，按待拍板 / 需修改 / 已通过 / 已驳回筛选，展开看证据和验证计划。
- **AI 工作**：company.log 式审计流（谁、什么时候、做了什么、hash 前 8 位），外加链完整性自检。
- **数据源**：状态表（状态、最近成功、节奏、快照数）。
- **设置**：全局暂停开关、版本与库结构、审计链状态、权限边界说明。
- **问 CEO**：右侧抽屉放宿主原生会话，只预填草稿，**由你确认后发送**。

## 与参考视频（Phoenix Tree AI）的关系

视觉形态按参考改造，但数据来源没有照搬：

- 参考实现源码在 `C:\Users\Administrator\Downloads\测试\dsh-ai-company-dashboard`（FastAPI + Python 独立后端），
  它只有静态示例数据和一个跑在 8766 端口的本地服务。本工作台**没有**引入它，数据仍然走 DSH 里的 SQLite 快照。
- 取的是它的**形态**：顶栏 7 Tab、创始人 → CEO → 6 路 Agent 的树、彩色连线 + 流动光点、
  模块色贯通连线与子卡、黄灯代表数据旧、Agent 卡上「上次 → 下次」、company.log 审计流、详情页 14 天柱图。
- 不取的部分：写死的示例数字（`$309`、`+47` 之类），以及它的占位仓库身份 `github.com/local/...`。

## 安装

在工作台市场里「本地开发」安装，或直接打包装进本机 DSH Desktop：

```bash
npm run build      # 生成 lib/client.js
npm run check      # 包校验（入口、清单、占位符、体积、敏感信息）
npm test           # 数据库 / 审计链 / 本机 API 冒烟测试
pnpm pack          # 产出 .tgz，用 Desktop 的本地安装入口安装后重启
```

数据目录：`$DSH_HOME/agent-new-media-studio`（默认 `~/.dsh/agent-new-media-studio`）。
里面是 `company.db`（SQLite WAL）、`snapshots/`（原始文件）、`audit/`（导出）。**卸载插件不会删除它。**

## 接口

所有接口在 `/api/agent-new-media-studio/` 下，只接受本机回环请求，`no-store`，无 CORS。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/health` | 自检，不含敏感信息 |
| GET | `/bootstrap` | 首屏数据（模块、数据健康、计数、审计链状态、近 14 天快照相减） |
| GET | `/today` | 轻量刷新（计数、数据健康、最新简报） |
| GET | `/detail/<moduleId>` | 单个模块详情（数据源、近 14 天、观测、决策、任务） |
| GET | `/modules` `/sources` `/decisions` `/tasks` `/audit` | 列表 |
| POST | `/settings/pause` | 全局暂停（需要 `x-agent-new-media-studio-request: 1`） |

## 安全边界

- 只回环访问；写操作要求自定义请求头 + `application/json`；请求体上限 1 MB。
- 错误信息不回显堆栈、绝对路径或密钥。
- 审计链 `hash = sha256(prev_hash + canonical_json(event))`，只追加；设置页可一键校验。
- 投资数据的模型出口当前设为「完全允许」（按使用者选择），可在模块配置里改回禁止。
